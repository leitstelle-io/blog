# Does the game run in the browser?
No. Leitstelle is a desktop game for macOS, Windows and Linux, built with Rust and Bevy. That's what it takes to run a whole district in 3D with fire, water and co-op multiplayer smoothly.

The earlier browser version was an important step along the way. What became of it is in the post [Coming full circle](/en/blog/2026/10/full-circle).
